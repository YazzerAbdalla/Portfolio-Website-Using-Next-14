# 🌐 My Developer Portfolio

This is my personal **developer portfolio website**, built to showcase my work, skills, and experience, and to create new opportunities for **jobs and freelance projects**.

I designed and developed it with a focus on **clean design, smooth animations, and modern technologies**, so that it reflects both my technical abilities and my creative side.

---

## ✨ Features

* **Home Page** – Engaging landing section with smooth animations.
* **Projects Showcase** – Displaying my best work with live links and descriptions.
* **Resume Page** – Easy access to my resume for recruiters and clients.
* **About Me** – A personal introduction and career background.
* **Contact Form** – Simple way to reach me directly.
* **Fully Responsive** – Works seamlessly across devices.
* **Modern UI** – Built with a mix of **Framer Motion** animations and **shadcn/ui** components.

---

## 🛠️ Tech Stack

* **Next.js 15** – React framework for performance and scalability
* **Sanity CMS** – Content management for dynamic project updates
* **Tailwind CSS** – Utility-first styling
* **shadcn/ui** – Modern, accessible components
* **Framer Motion** – Smooth and elegant animations
